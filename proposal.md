## Description
I will be creating the game hangman.  Hangman is a game where you make a sentence and the other person has to guess what the words are before the man gets hanged.
## Features
- Feature 1
	- The game will first introduce you to the game, and will present to you some.  I will use print to introduce the player.
- Feature 2
	- The next feature will include the program providing hints, or give a beep to show incorrect.  I will use if statements to implement the incorrect system
- Feature N
- The additional feature for the game will include the game visually adding the body parts of the hangman, as a way to show how close they come to fail.  I will use variables to create the parts.
## Challenges
- The challenges will include the user guessing what the word is
- The user will also have to think of what the hint can imply
- Additionally the user should think of common letters or vowels used in the English language to guess the word.

## Outcomes
Ideal Outcome:
- The ideal outcome would be the user to guess correctly before the man is even formed.

Minimal Viable Outcome:
- The Minimal Viable Outcome would be the user to guess correctly just before the man is one step away from being formed and hung.
